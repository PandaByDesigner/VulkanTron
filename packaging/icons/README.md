# Faithful Remaster launcher icon

`gltron-faithful.png` is a new app-menu icon generated with the built-in image
generation tool on 2026-09-12. It identifies the app in desktop launchers and
the project README; it does not replace any original or faithful in-game artwork.

The returned opaque RGB PNG is 1254 by 1254 pixels and is used unchanged.
Desktop launchers scale it for display. SHA256:
`b73e47fa92cc7e6cef0f6ff5a40412d179461e256e9104644aa6bff5e57edb56`.

## Generation prompt

Create one finished square Linux desktop application icon for an unofficial
game called GLTron Faithful Remaster. New launcher artwork only, not in-game
art. No text, no letters, no numbers. An iconic classic low-poly lightcycle in
bright electric cyan and pearl silver, viewed in bold three-quarter profile,
with two very readable luminous circular wheels and a short gold-yellow
right-angle light trail behind it. A subtle purple grid recedes below it. Deep
midnight navy square background, rounded tile silhouette drawn within the
canvas, fine cyan rim. The lightcycle silhouette fills most of the tile and
remains legible at 48 pixels. Strong simple geometry, clean edges, a restrained
classic 1990s arcade rendering aesthetic, polished but not photorealistic, soft
controlled glow, strong contrast. Centered composition with 8 percent safe
padding on every side. Precisely square canvas, 1024 by 1024 pixels. Opaque
background, no transparency, no checkerboard, no collage, no mockup, no multiple
variants, no watermark. The cyan single cycle and yellow angular trail must
clearly distinguish this from the old GLTron icon showing two yellow and blue
cycles.
